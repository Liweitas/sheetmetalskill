# 新箱体默认结构选型（2.4.1完整入口）

先将L、W、H统一为mm并核尺寸口径，取M=max(L,W)。适用于没有显式结构选择的新箱体设计：

- M≥H：侧—底—侧U型件＋两块外封端板＋盒盖，共4个钣金件；盒体本身3件。
- M<H：三面U围＋底侧L件＋盒盖，共3个钣金件；盒体本身2件。

相等归第一类，是此次明确告知的边界约定。L/W互换不改变类型。计数不包含把手、紧固件；无盖项目不因本规则增加盖。U件沿哪一轴通长、接缝与端板具体轮廓由项目几何决定，不能从类型比较自动推定。

显式项目结构选择优先；既有已确认项目保持原结构，不自动迁移、批改CAD或旧交付。结构选择仅为默认设计路线，不等于深U折弯、反边、退刀、焊接装夹、装配干涉、真实展开或首件检查通过。

实际生成用scripts/build_package.py：resolve_job调用本选择器，结果写入兼容旧2.2记录的2.4 canonical schema；u_wrap_bottom_l与bottom_l角色已接入。单独运行select_structure.py仍只返回建议。显式选择和既有项目保护不变。

本次四款均归第一类。其201/t、孔位解释、U通长方向、端板轮廓退让（当时0.2；2026-10-26 起默认0，见文末）、盖裙20、箱口内折20、q/Ri/角缝、把手数量和其余孔距均为各项目参数，不由本结构政策设为全局默认。端板轮廓退让和轴向装配间隙必须分开；匹配圆角应明确各自圆心/半径。

- 本选型对新箱体为**强制**：用户未明确指定结构时，max(L,W)≥H（含相等）→ 侧-底-侧U + 两外封端板 + 盖；否则 U围 + L + 盖。用户明确选择优先。取代 v2.8.2 曾写的“brief 未写 structure 一律 u_l_t7u”。
