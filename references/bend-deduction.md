## 口算

- 常用系数 **1.6~1.7**，多数 **1.7**：`BD ≈ 1.7 × t`（例 t=2 → 3.4）。
- **本厂 201 / t=2.0：实测 BD=4.24**（t116u 对 v18 实物机测；**优先于**先前口头 3.3）。

## 与 BA / ANSI K（90°）

```
BA = 2 × (Ri + t) − BD
K  = (BA / (π/2) − Ri) / t
```

本厂例（实测）：t=2，Ri=2，BD=4.24 → BA=3.76，K≈0.196845172（PDF 可写 K≈0.197）。

旧口头本厂（已取代）：BD=3.3 → BA=4.7，K≈0.496（仅作历史对照；勿再用于新展开）。

SheetMetal / 展开入口用该 K（或固定 BA）重算；PDF 材料栏/折弯表写明 BD 来源（实测 / 口头 / 候选）。
