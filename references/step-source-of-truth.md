# 有源 STEP 几何真源与差异表（用户硬性规则17｜v2.8.15）

来源：用户 t95u / t96u / t97u，2026-10-31（Asia/Shanghai）。与 `SKILL.md` 用户硬性规则17 同步；有冲突以 SKILL 条文为准。

## 何时适用

订单附件或现场目录含**源 STEP**（客户/上游几何），且本单将出确认稿、重建 job、或海军蓝折弯 PDF 时，一律适用。无源 STEP、纯文字尺寸新建箱体时，仍走既有规则4–16 与选型默认。

## 权威分层

| 层 | 管什么 |
|---|---|
| **源 STEP** | 孔型（通孔 / 沉孔 CSK / 攻丝底孔）、孔径、CSK 外 φ 与角度/深度、品字口/IEC 开口尺寸与朝向、接口螺钉孔、孔位坐标、板厚、外轮廓包络 |
| **文字 / brief** | 仅补 STEP 无法表达：料号、qty、公差说明、工艺备注、把手/铰链等请求标志、材料牌号确认等 |
| **工厂默认（规则4 M4 等）** | 仅当 STEP **未**给出该紧固孔型/孔径，或用户**明确**选用工厂体系并书面批准偏离 STEP 时使用 |

## 强制流程

1. **测 STEP**：按零件读源 STEP（单位、板厚、外廓、每孔心/径/轴、沉孔锥/柱段、矩形/异形切口方向与尺寸）。可用 `scripts/step_dimensions_readback.py` / `scripts/step_audit_cad.py` / 既有审计入口作证据，不替代人工核对关键孔。
2. **填 EVIDENCE 差异表**：对比 STEP vs 当前 job / 拟重建 / 拟 PDF；先给用户看，再决定是否改图。
3. **冲突确认**：尤其「工厂 M4（箱体 Φ3.3 攻 / 盖裙 Φ4.5 通）vs STEP 沉孔或其它 φ」——**必须问用户**；用户未选工厂体系前，**STEP 赢**。
4. **按 STEP 特征重建 job**：孔型、φ、CSK、品字/IEC、螺钉孔、坐标、板厚、外廓写入 job/cfg；文字默认不得静默覆盖。
5. **同一 PDF 页图**：海军蓝 `make_bend_pdf` 页结构与重建一致（ASSEMBLY / U / L / LID / END_… 等与文字重建同结构）；每零件页孔表与切口 = 重建几何 =（有源时）STEP。禁止 PDF 另讲分叉故事线。
6. **记批准偏差**：任何用户批准的 STEP 偏离，写入确认稿 README、PDF 说明、订单/技能相关 CHANGELOG。

## EVIDENCE 差异表清单（最低列）

每行一个特征；缺列不得省略为“差不多”。

| 列 | 说明 |
|---|---|
| 零件 | 如 LID / U / L / END_L |
| 特征 | 如 盖裙固定孔-1、品字口、IEC、线孔A |
| 类型 | 通孔 / 沉孔(CSK) / 攻丝底孔 / 矩形切口 / 其它 |
| φ（或开口） | STEP 实测 vs job/重建；圆孔写直径，品字/IEC 写长×宽 |
| CSK | 外 φ、角度、深度；无则写「无」 |
| 坐标 | 相对约定基准的孔心或切口定位；注明坐标系 |
| 判定 | 一致 / 冲突 / 仅文字有 / 仅 STEP 有 |
| 处置 | 跟 STEP / 跟用户批准工厂默认 / HOLD 待问 |

建议另附：板厚 t、外廓 L×W×H（或本件包络）、品字/IEC 朝向（横向/竖向）。

## 反例（禁止）

- STEP 盖裙为沉孔，重建/PDF 写成 plain Φ4.5 通孔且未问、未记偏差。
- STEP 盖有 IEC/品字口，文字重建漏切或朝向改竖装且未审计。
- 海军蓝 PDF 页顺序/零件集合与重建不一致，或孔表与 STEP/重建分叉。
- 以规则4「无特殊要求 M4」为由，在**已有源 STEP 孔型**时静默覆盖。

## 与其它规则

- **规则4**：无源 STEP（或 STEP 未定义该孔）时仍用 M4 默认；有源且 STEP 不同 → 见规则17 第5款。
- **规则5 / 16**：接口攻丝标注、品字横向等默认，在 STEP 已给出尺寸/朝向时以 STEP 为准；STEP 未给朝向时再落规则16 默认。
- **既有 STEP 审核**：[existing-step.md](existing-step.md) 管「不要把未知既有 STEP 擅自当新箱重建」；本文件管「订单已带源 STEP 做出图/重建时，几何真源与差异表」。二者同时适用时：先审计差异，获授权后再重建，重建仍须对齐 STEP 特征。
