# 工具映射、能力边界与替代路线

以下能力来自已实践的FreeCAD/SheetMetal流程；名称是探测目标，不是跨版本API保证。本技能不携带本机程序路径、插件安装包、CAD引擎或客户模型。每次在当前环境发现工具/文档、核实连接并用小型只读动作确认返回结构，再运行建模。

## 实践过的能力

| 环节 | 已实践的接口/工具 | 能证明什么 |
|---|---|---|
| MCP建模/读图 | FreeCAD MCP `execute_code`、`get_view` | 在实际运行的FreeCAD中执行代码、取得原生视图；工具返回成功仍要检查产物 |
| 工具发现 | MCP会话初始化和工具列表发现；可发现`list_documents`/`get_objects`等 | 发现不等于已经调用或已经连上CAD；只报告实际执行的工具 |
| 本机连接 | stdio MCP程序连接运行中的FreeCAD RPC插件 | 主机/端口/程序从本机配置取得并实测，不写死路径、固定端口或自动安装未知软件 |
| STEP核读/实体 | FreeCAD `Part.read`、`Shape.Solids/Faces/Edges`、`isValid`、`Volume`、`BoundBox`及曲面/圆边 | 使用FreeCAD所带OCCT几何；不是另一个独立CAD内核的复核 |
| 成形重建/干涉 | Part的线/圆弧/面/拉伸/圆柱孔、offset、fuse/cut、`common` | 真实实体、孔和求交；授权现场修整的交叠要保留原实体，`common`只用于测量/辅助模型 |
| 真展开 | 安装的`SheetMetalNewUnfolder`；历史实践接口`BendAllowanceCalculator.from_single_value(K, 'ansi')`、`getUnfold(...)` | 钣金展开体和弯曲信息；根面、K定义、返回结构/异常必须运行时核实 |
| 三视 | FreeCAD `TechDraw.projectEx` | 成形HLR可见/隐藏边；检查返回分组、坐标方向和投影视图，不当作展开 |
| 导出/爆炸 | Part/FreeCAD STEP导出、原生CAD保存、复制形状后刚体变换 | 分件与装配/爆炸几何；保留实体数及每件变换 |
| DXF | 从真实展开边界写ASCII R12，再重新解析基本实体 | 明确图层/单位/轮廓；自定义写/读可能共享缺陷，需要几何重建及面积/孔对比 |
| 几何回读 | 导出的STEP重新`Part.read`；DXF边重建Wire/Face并检查面积/闭合 | 文件与模型的一致性；允许数值容差须注明，不能当制造公差 |
| 预览 | 实际STEP回读后`Shape.tessellate`及空间边，Matplotlib；已写DXF重新解析绘图 | 文件输入链的可见性/对应关系，不代表用户CAM或机台通过 |
| PDF | ReportLab、pypdf、`pdftoppm`及逐页图像检查 | 排版/文本/视觉证据；引用当前环境可用PDF技能的创建/验证规范 |
| 封包 | `hashlib` SHA256、`zipfile` CRC与逐文件解压SHA对比 | 源保护与包完整性，不是制造质量验收 |

在一次历史实践中，MCP Python SDK的字段名从camelCase变为snake_case；这类问题应检查运行时对象/版本文档并适配，不能盲目粘贴旧调用。工具名称和返回项也可能变化。

## 替代路线与停点

- 有可用专用CAD连接器/API/CLI时优先使用其实际能力。没有MCP但有可运行FreeCAD环境，可用受支持的宏/无界面脚本运行同一几何与展开检查；先验证当前环境的导入、SheetMetal依赖和无GUI能力，不默认可用。
- 其他CAD的原生钣金展开可作为替代：记录工具/版本、基准/K或补偿定义，并重新核验成形、展开、孔和导出。不以更换软件免除回读校验。
- 只有普通STEP查看器/几何库且无法真正展开：仍可做源审计、装配求交及成形预览；下料展开标为`blocked`，不能交“投影展开”。
- 只读探测证实连接失败后，区别权限限制、服务未启动、接口不兼容和几何/展开失败。使用当前平台允许的正规授权路线；不要改安全设置、循环重启崩溃GUI、另装未知软件或把旧任务“不可用”当成本机事实。
- 外部CAD/CAM导入或机台试切，只有实际获得该应用并执行验证后才加入证据。依赖未连接/无权限时报告具体缺口，不承诺日后自动可用。

## 提速的实际边界

适合自动化的是参数/来源记录、几何SHA缓存、原生展开批处理、同版文件生成、孔表映射、回读检查和固定图纸版式。工艺拆件、定位选择、功能尺寸取舍、刀具可达及首件/放行仍需相应工程或现场证据。

保持CAD计算、DXF导出、预览和PDF排版的依赖分开。改一页文字只重绘该页并更新清单；只改盖时缓存盒体；跨部件配合/材料/厚度变化按[参数依赖表](parameters.md)扩大校验范围。几何通过后不为版式反复重建所有CAD，也不在修改同一个状态文件的任务间并行覆盖记录。
