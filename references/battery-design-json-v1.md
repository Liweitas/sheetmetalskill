# 电池盒设计 JSON v1：源坐标和制作输入

来源：用户于2026-11-18提供《电池盒设计 JSON 字段说明》。这是源设计器的格式契约，不表示目前制造入口已实现所有类型。遇到设计器JSON、`freecad`扩展、图片孔位或把手偏移时先读本文件。

## 文件与适用边界

- “保存方案”文件通常为battery-box-design.json；`version`只认整数1，毫米，UTF-8字节数小于4MB。最多48孔（含把手展开安装孔）、80组件。顶层box、holes、components；新版另有freecad。
- 保存方案是编辑快照，不是制造需求单，更不能直接当CUT或BEND。确认并提交的后台需求格式为`boxlab.production-request.v1`，另含材料/数量/备注、孔心孔边、组件和设计快照。
- 材质、数量、备注、提交人、空间审核/报工状态不能从设计JSON推断；订单行及最新用户指令仍要单独记录。

## 高度和板厚

源`box.height`是盒体高度，**不含上盖厚度**；源合盖总高读`freecad.box.total_height_with_lid`，没有扩展时按源height+lidThickness核算。不要继续把所有来源的height直接当含盖高。

这与本项目制造brief“高含盖”是两种口径：源字段须转换并记录来源；用户明确指定的含盖总高优先。订单板厚覆盖源板厚时，不偷偷改孔中心，也不自行决定把源合盖高保持还是重算；存在影响成品尺寸的冲突时先厘清本单基准。既有订单不得因新增说明静默重出或改变已确认尺寸。

源length/width/height范围30–1000；wall/lidThickness范围1–20。源内长=L−2wall、内宽=W−2wall、内高=height−wall，内腔各向至少10。源lidStyle为hinged/screwed，缺省hinged；screwInset缺省12，指螺钉盖四角螺钉距外边，铰链盖保留但不用。不把这些源默认值当作用户制造授权或擅自生成承接片。

## 孔与坐标：不要多加板厚或外伸

- holes中face取front/back/left/right/lid/bottom；circle/rect；u/v始终是**面中心相对孔心偏移**，u向右、v向上。width/height是直径或矩形宽高；圆孔两者相等，width不是半径。
- 可选`measure:"edge"`仅表示界面以孔边编辑，不改变u/v孔心语义。
- 界面的“距左/距下”从**可开孔区域左下角**起量，不必等于物理板外边孔心距。识别图片必须记录它标的是孔心/孔边、可开孔区域/实际边；不把所有截图数字统一当作外边孔心距。
- 有`freecad`时优先用每孔`center_global_mm`及`drill_axis_inward`。世界原点为盒体外部前左底角，X右、Y后、Z上；切入向量由外向内，不能默认为Z轴。各面映射按孔内明确axis信息读取，不把前面方向复制到后面或左右面。
- 用`sketch_mm`时，明确读`origin_global_mm`及x_from_left_to_center/y_from_bottom_to_center，草图基点为可开孔区角点，**不是外轮廓角点**；孔size_mm.diameter/radius分别是直径/半径。相对草图量换成世界量只加一次明确基点。
- 用户明确规定物理板边的孔心/孔边尺寸时，遵守实际盖边基准规则，不再补源板厚、制造板厚或盖外伸。图片识别出的明确值原样保存，不居中、不四舍五入改位；读不清或基准未定的值保留未定，不从旧单补。
- 源说明例：L240、wall3、前面u=-65得到世界X55；可开孔区基点X3，故界面距左52。示例世界Z46.5、基点[3,0,3]；该例不是任意订单的通用常量。
- id为1–80位字母数字下划线或连字符，孔与组件全方案唯一。孔坐标范围±2000，孔尺寸1–1000。新扩展和旧u/v不一致时记录并核对，不能任选一种掩盖冲突。

## 把手、内部组件和产品

把手kind=handle，face/u/v为面中心位置，rotation只能0/90/180/270；源不保存四安装孔，制造时按85/62/30、4×Ø6.6逐实例展开、核朝向。明确的偏置保留，不自动镜像/归中。**本单说不要把手时同时去掉该把手及其安装孔，不改变其它功能孔**；不推广为所有订单无把手。

内部21700/18650/bms：x沿长、z沿宽，内腔中心0；y是组件旋转后底面距内腔底面的高度；width/depth/height保留原始尺寸，电芯width=depth。orientation缺省[0,0,0]，XYZ Euler，角度仅0/90/180/270。组件坐标±2000、尺寸1–1000，name去首尾空格后1–48字符。不把这些预览组件自动算成待下料板件。

`kind:product`实例使用face/u/v/rotation，内嵌product.kind为imported，含name/model/axis、局部安装孔、可选size_mm、mesh.positions/triangles及source_sha256/filename。孔随换面与旋转；不能重复生成到顶层holes和freecad.holes。freecad.holes/制作需求会展开关联孔。厂家axis仅x/y/z，不区分正反，需核安装基准。网格只是预览，不替代原生STEP；JSON中的哈希不证明原文件已验证。普通航空插头可能只剩普通孔，不编造已丢失的规格关联。

## 进入加工文件前

记录原始JSON/图片/订单行、采用的高度和厚度基准、逐孔世界坐标或明确物理边距；再核实际成形STEP、原生展开、CUT/BEND/NEST一致性和外视手性。文档记录通过不等于制造器支持或CAD通过。红蓝六页PDF首页原图、完整ZIP等既有要求继续执行。
