# 行为反例

1. 明确无盖、无螺母时，计划中加入盖件或压铆安装孔：阻断范围冲突。源模型存在盖件不覆盖目标需求。
2. 带盖压铆时，缺少具体型号、硬度或公差：保持HOLD；材料或厚度改变后旧选型/标定不得沿用。
3. 只改指定孔时，另一孔、无关件或编辑区外几何随之变化：阻断窄改；源/新文件SHA和真实CAD对比证据必须匹配。
4. 用户要求与源事实混用：用户选定材料不代表STEP可测出该材质。目标同时要求body_only与lid_required则属于同层矛盾。
5. 已知参数填unknown却保留数字，或未知量填零：阻断；未知、零和不适用分别处理。
6. 沉座数学连续，但头型/实料厚度/薄壁验收或加工可达未验证：只交有边界的审核草案。历史余厚不能当通用合格线。
7. 未知折弯数绕过补偿、零目标尺寸、压铆关联螺钉角色、非法快照/NaN：结构化阻断，不崩溃。
8. DXF实体非空但外圈自交、零面积或圆孔越界/相交：阻断。基础平面检查仍不替代成形孔轴、实际展开和CAM验证。

[虚构软件夹具](../assets/examples/SYNTHETIC-EXAMPLES.md)只演示这些检查，不提供真实CAD、硬件选型或加工依据。
