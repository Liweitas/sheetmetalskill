## 默认与显式值

新有盖矩形箱体缺省盖裙统一15mm，来源为用户通用规则；记录为默认且待本款确认，不按板厚、尺寸或孔位自动提高到16/17/20mm。用户显式12.34mm等值按输入精度保留，仅做明确单位换算；不能改值后仍标用户指定。其他显式Ri/g/q/角缝也保留本次来源。历史客户显式裙高不因新默认批量改写。

入口层次须区分：通用brief由 `build_general_package.py` 编译经验默认与本款计算；底层显式job/03适配器消费已解析参数，不自行猜测缺失工艺值。旧底层说明中“q或裙高无默认”描述该显式参数层，不得用来取消通用入口的新默认15，也不得将通用经验值强加既有STEP。q与g仍是独立参数；通用入口给出的本款顶隙计算候选必须显示来源及对体高的影响。

默认不是可制造保证。t2、Ri0.8、角缝0.2的已知原组合存在微小角部自交，真实几何检查应拒绝，保留原输入和失败证据。默认15与原角缝0.2均不得为凑通过静默改变。

如需研究避让，用独立派生入口写新brief：

```bash
python3 -B scripts/derive_corner_candidate.py /ABS/baseline.json \
  --output /ABS/new-corner-candidate.json \
  --source '本次角部自交诊断及调整建议的证据引用'
python3 -B scripts/build_general_package.py /ABS/new-corner-candidate.json \
  --output /ABS/new-candidate-archive
```

该工具按本款t/Ri等计算候选，不把0.4固定为通用默认；上述t2/Ri0.8例计算得到0.4。派生记录保留基线brief哈希、原角缝、候选值及待确认来源。候选须重新真实成形、展开与03核查；即使数字文件生成成功，仍HOLD，不等于用户确认改尺寸或工厂生产放行。不得覆盖基线或重复套用派生候选。

## 师傅作业册

`cn_workshop.py`用于完整制造路径；全中文说明，不打印英文日志或完整来源字典。首页突出材料牌号、板厚、套数、尺寸口径、图纸修订、状态、Ri、K及90°弯曲补偿/折弯扣除。未标定K及现场刀模不得伪装已确认。mm/R/M/K、零件号和坐标轴等技术符号可使用。

每件使用同版实际成形投影及真实展开数据：

- 成形三视及轴测斜视标真实轴向尺寸；装配只给实际总外形和关键配合，逐件图给本件尺寸。
- 展开图标真实平坯尺寸、原点、弯线编号；逐弯列位置坐标、方向、角度、Ri、折序候选及靠边候选。无依据不填写可执行机床后挡料；翻面、刀具碰撞、回弹和折序须实折核实。
- 03局部图从实际展开轮廓取点与标注，不能只画模板示意。03是盖裙角部方案，不是0.3mm接合缝。
- 爆炸图来自同一零件的平移并标原零件成形尺寸；不把爆炸移位计入产品尺寸。装配总外形来自未平移装配。
- 孔径/坐标与工艺参数同源；拥挤时用孔表或局部页，不能靠省略尺寸换整洁。审计长文、逐参数来源和限制证据另存JSON/CSV及 `GENERAL_PARAMETER_REPORT_*.md`，不塞入作业册。

`cn_confirmation.py`仅用于确认稿：有真实报告/投影才展示带尺寸成形图；材料未知、缺参、异形或工艺冲突按实际状态列中文确认事项，不编造CAD、展开或机床程序。实际交叠保持数值，调整建议明确未采用；现场修配只接受已绑定本项目的真实授权，不从其他客户继承。

## 命名、历史与交付

正式编码仍为 `S/X-材料代码-板厚-YYYYMMDD-四位编号-vN`。材料描述与代码通过[R12映射](R12-material-code.md)绑定，不把201不锈钢改成示例Q235。缺工厂编号等字段标未命名待确认，不阻支持范围内建模，也不得伪造正式身份。目录、完整折弯PDF、套料DXF、套料预览PDF、其余文件及唯一ZIP共享主码和用途后缀。

旧包经命名发布只改变受控副本命名与发布记录，保留原CAD/DXF/PDF字节；因此旧PDF不会自动变成最新中文作业册。应分别报告源工程版本、发布版本和实际PDF模板契约；需要新模板须在授权新修订中生成并重新核验，不能仅更新说明或哈希宣称完成。

每客户/需求、每修订同目录归档；完整门禁核文件、参数/数量、实际几何、套料、PDF、哈希和ZIP，默认最终只发一个完整ZIP。用户明确先看确认图或索要单件才按本次范围例外。脚本只能验证送检消息计划，不能保证所有智能体实际发送行为。

既有STEP走 `audit_step.py` 并保留原结构/材料未知/源缺陷；只提供 `SOURCE_AUDIT_ONLY_PARTIAL_HOLD` 审核资料及槽位状态，不能称工艺齐套。诊断展开、审核PDF或新箱体生成成功不能替代源件工艺验证。

## 验收与安装顺序

完整实际回归至少包括两种结构、默认15与显式12.34、材料映射正式命名与缺编号、无孔/无把手、原冲突拒绝与独立候选、源STEP限制以及原关键负例；检查同版STEP/爆炸/展开/CUT/BEND/套料/中文PDF/ZIP并重新解包读回。PDF须全页渲染目视，自动文本和矢量检查不能代替可读性检查。

先冻结完整包和SHA，再独立验收；通过后备份本机旧v2.3.0及两处skills符号链接关系，再安装已验收同一哈希内容。全新调用上下文核实际加载路径、版本、文件清单哈希并完整烟测。当前尚未执行这次安装，也没有宣称R12整包已通过；不得把历史R10限定通过扩大为此候选通过。
