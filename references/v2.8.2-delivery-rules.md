## 2 已验证默认值（全部标“经验/待首件”，不是放行值）

## 3 DXF / 套料（自动门禁 `scripts/release_dxf.py check`）

- DXF_CUT/`<VER>_CUT_<n>.dxf`：只 CUT 层，LINE/ARC/CIRCLE/LWPOLYLINE，全部 CONTINUOUS，mm（$INSUNITS=4），1:1（bbox = 展开尺寸），闭合、无零长、无重复、无共线重叠/同心弧重叠。
- DXF_BEND/`<VER>_BEND_<n>.dxf`：OUTLINE（外形+孔）+ BEND 层（折弯线，**连续实线 CONTINUOUS，禁止虚线**，红色＋文字）+ TEXT（B号/方向/Ri）；**只给折弯师傅看，不进 CAM**。
- NEST（发布默认，用户 t62u 2026-10-28 / v2.8.7）：`<VER>_NEST_2440x1220_1BOX.dxf` —— **一盒一个 DXF**，只排 1 套完整盒体零件（各件×1），只 CUT + SHEET 两层，SHEET 为原点处闭合 2440×1220 框，边距 10、件距 10（外形 bbox），**不许 BEND 层/虚线/文字**；订单 qty 只写 README/BOM，不复制多套、不拆 `SHEETnn`（现场师傅自调套料）。套料预览 PDF/PNG = 1 页/1 张。旧 `SHEETnn` 仅内部/证据可选。CUT 与 NEST 二选一进 CAM。
- 原生 `delivery_contract` 套料没有 SHEET 框，`release_dxf.check --role nest` 会判 FAIL —— 原生套料只作证据，发布套料一律由 `release_dxf.write_nests` 写。

## 4 PDF（A3 全中文 ~4 页）

- 用户 t16u：页数尽可能压缩，参考当前 4 页版式（总装1页 + 每零件1页：三视/展开/折弯表/孔表同页；镜像同件合页），不另加说明页；`release_package.py package --pdf-max-pages N`。
- 页数少但尺寸必须齐全：每个展开图上每个孔、每条折弯线、每个缺口都有坐标尺寸；每件孔表（孔径/攻丝规格+底孔/坐标）与折弯表；A3 原尺寸文字 ≥约3.3 mm（≈9.4 pt）。接口螺钉孔写“攻M_ / 底孔Φ_”。

- 每页：发布名、材料、板厚、外形/总高醒目；页码 n/4；“计算检查通过”与“实物试折试装：未进行”分开写；production_release=false。
- 内容：总装三视+轴测（带真尺寸线）、各件展开（DXF 同源）、剖面（间隙基准：盖裙内面↔箱体外面）、局部；逐件折向/折序/角度/Ri/关键成形尺寸/焊接。
- 尺寸必须**从本版 DXF/STEP 读数**（L§3.2，`pipelines/u_l_t7u/make_bend_pdf.py` 记 `bend_pdf_dimension_sources.json`），真尺寸线（延长线+箭头+数值），文字/线条碰撞检查写 `bend_pdf_layout_check.json`（L§3.3–3.4）；渲染后逐页看图。

- **配色管线（用户硬性规则12 / v2.8.9）**：确认稿折弯 PDF 必须用订单 `addendum-tools/make_bend_pdf.py`+`pdf_common.py`（海军蓝页眉+红条材料栏+蓝尺寸+绿盖褐箱）；禁止灰框 `tools/pdf.py` / `*_BEND_DRAWING_A3.pdf` 顶替交付；CJK 子集按本单字面现建。

## 5 命名与打包（`scripts/release_package.py package`）

- 发布名**原样使用**：只允许 `[A-Za-z0-9._-]`，否则 FAIL 并问用户；**从不规范化、从不自编编号**。
- 发布目录每个文件以 `<VER>` 开头；文件名与 zip 条目全 ASCII（内容可中文；中文 PDF 名改 `<VER>_BEND_PDF_A3_CN.pdf`）；无点文件/__MACOSX/嵌套 zip/FCStd 备份。
- **每次发布一个完整 zip**，全部条目在 `<VER>/` 下，显式 (源, 条目名) 映射整包重打，testzip + 逐条字节比对，旁边写 .sha256（L§5.7–5.8、L§6.3）。
  L§5.7/§7 的“中文名 PDF 只放 zip 外”与“一个完整 ZIP”冲突 → v2.8.2：PDF 必须在 zip 内（ASCII 名）；zip 外可另放同字节中文名副本，但不作为第二个交付物。
- 版本一致：STEP 头（FILE_NAME/FILE_DESCRIPTION）、DXF `$RELEASE` 自定义变量/文字、PDF 每页文字都含 `<VER>`；STEP/DXF 出现别的发布名 → FAIL；文档/PDF 引用别单 → WARN（只能是来源引用）。
- 重名扫描：`/workspace/orders` 下已有同名目录 → WARN（例：S-201-1-20261021-001-v1 同时是 400×220×150 和干画图3 的 465 阶梯箱）。
- 改名：`release_package.py rename OLD OLDVER NEWVER NEW`（或 u_l_t7u 的 `rename_release.py`，L§1.5）——名称/文本/STEP头/DXF 文字换名，PDF 必须重渲染；断言几何哈希（STEP DATA 段、DXF ENTITIES 段）不变。
- **确认稿版本（用户 t69u / v2.8.8）**：工厂 vN 仅结构/尺寸/孔变化时升版（前五段不变，旧包进 SUPERSEDED）；PDF/打包等同厂版微调保留 live `{VER}_CONFIRM_DRAFT.zip`，另存 `revN` + CHANGELOG；助手 `scripts/snapshot_confirm_rev.py`。完整规则见[确认稿版本规则](confirm-draft-versioning.md)。

## 6 冲突自动检查（`scripts/conflict_checks.py`，WARN/ERROR 进确认稿“冲突与风险”）

1. Ri > g：q=0 时盖根圆角压箱体顶外棱 → 需 q（t1/Ri0.8/g0.5：q0 干涉0.054，q0.2 余隙0.129）。
2. M4 直接攻 t≤1.2 → WARN（缺省仍为 M4 攻丝——用户 t16u；t≤1.2 时必须输出薄板攻丝警告（用户 t52u）：“1.0 mm 201 板直接攻M4（底孔Ø3.3）仅约1扣有效螺纹，强度偏低、易滑牙，不建议反复拆装；替代方案 压铆螺母 / 拉铆螺母 / 点焊螺母 列为待确认”，写进 PDF、README、校核清单（文本用 `conflict_checks.m4_thin_sheet_warning_cn()`）；替代件只列待确认，不擅自改用——用户 t52u，2026-10-26）。
3. 深 U 第2道折弯：侧壁 ≥100 或 ≥0.5×内宽 → WARN，给出上模高度时侧壁+5>上模 → ERROR。
4. 孔边→折弯切线 ≥ max(3, 2t+Ri)（L§5.4；L§6.4 曾见 2.65 需挪孔）；孔边→外形 ≥4 由管线 clearance 检查。
5. 未要求的把手/顶孔/线孔 → ERROR。
6. `connector_screw_taps`：线孔/品字口等接口螺钉孔未写攻丝规格/底孔 → ERROR（用户 t16u）。
7. `joint_flush`：L盖U退让 / 端板退让 / 拼缝 / 长裙退让非0且无用户来源 → ERROR（用户 t16u：不留缝、不退让）。
8. `cable_hole_min_count`（v2.8.5，用户 t35u “线孔至少两个”）：params 有 `cable_holes` 时，1 个 → WARN（补第2个：同径同高同面，孔距25朝面中心，核间距，列HOLD）；0 个 → INFO（不凭空加）。
9. `hole_to_lid_skirt`（v2.8.20，用户 t99u / 审计 t98u 规则22）：有 H+skirt 时，箱体面线孔/IEC/电表口孔顶→盖裙下沿（H−skirt）；净空<0 → ERROR（msg 含「盖裙遮挡」）；0≤净空<10 → WARN；强制进 PDF p1 / CONFIRMATION / README（`lid_skirt_force_lines_cn`）；排除箱体 M4 / 盖裙螺钉孔。
